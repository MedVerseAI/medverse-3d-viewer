# AtlasView — MedVerse 3D Anatomy Viewer & Quiz

Standalone web-based Three.js 3D viewer and interactive anatomy quiz for models generated by `medverse-asset-ingestion` (compatible with both v0.2 canonical custom properties and legacy v1 GLB metadata). Supports desktop and mobile browsers, local serving, and containerized Nginx deployment.

---

## Obtaining `web/model.glb`

Large `.glb` binaries are not tracked in plain Git. Obtain `web/model.glb` via either method:

1. **Direct v0.2 Pipeline / GitHub Release (Recommended):** Download `anatomical_model_quest3_lod0.glb` from the [`medverse-asset-ingestion` Releases](https://github.com/MedVerseAI/medverse-asset-ingestion/releases) (or run `medverse run --profile quest3_lod0`) and place it at `atlasview_quiz/web/model.glb`.
2. **Legacy `.blend` Conversion Helper:** Copy `config.example.json` to `config.json` (leave `"blender_exe": ""` to auto-detect `BLENDER_PATH` or `blender` on `PATH`), set `"blend_path"`, and run:
   ```bash
   python convert_blend.py
   ```

---

## Build & Run With Docker

From `atlasview_quiz/` (once `web/model.glb` is present):

```bash
docker build -t atlasview:latest .
docker run -d --name atlasview -p 8080:80 --restart unless-stopped atlasview:latest
```

Or using Docker Compose:

```bash
docker compose up -d --build
```

Open `http://localhost:8080`. Container health is monitored at `http://localhost:8080/health`.

### Local Dev Preview (No Docker)

```bash
python3 -m http.server 8080 --directory web
```
